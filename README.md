# ブロック図エディタ

インストール不要のソフト設計用ブロック図作図ツールです。  
`index.html` をブラウザ（Edge / Chrome）で開くだけで動作します。

## 起動方法

```
index.html をダブルクリック
```

依存ライブラリなし・サーバー不要・単一ファイル完結。

---

## 基本操作

| 操作 | 方法 |
|------|------|
| ブロック作成 | ツールバー「ブロック」→ キャンバスをドラッグ |
| 矢印作成 | ツールバー「矢印」→ クリックで折れ点追加、ブロック辺でクリックして接続 |
| 選択 | ツールバー「選択」→ 要素をクリック |
| 複数選択 | Ctrl+クリック |
| テキスト編集 | ブロック／矢印をダブルクリック |
| 削除 | 選択後 Del キー または「削除」ボタン |
| アンドゥ／リドゥ | Ctrl+Z / Ctrl+Y |

---

## ツールバー機能

### ツール
- **選択** (V) — 移動・リサイズ・選択
- **ブロック** (B) — ドラッグで新規ブロック作成
- **矢印** (A) — クリックで折れ点追加、ダブルクリックで確定

### グループ
- **グループ** (Ctrl+G) — 選択中の要素をグループ化
- **解除** (Ctrl+Shift+G) — グループを解除

### 編集
- **削除** (Del) — 選択中の要素を削除

### テキスト縦位置
- **⬆ 上 / ⬛ 中 / ⬇ 下** — ブロック内テキストの縦位置を変更

### 等間隔配置
- **⇔ 左右均等** — 選択ブロックを水平方向に等間隔配置（3つ以上）
- **⇕ 上下均等** — 選択ブロックを垂直方向に等間隔配置（3つ以上）

### 文字色
- **A 文字色** — ブロックのテキスト色を変更

### ファイル
- **💾 保存** (Ctrl+S) — JSON形式で保存
- **📂 読込** — JSONファイルを読み込む
- **📷 PNG** — 透過PNGとして書き出し（ブロック・矢印のみ、背景なし）

### 背景
- **背景** — キャンバスの背景色を変更（デフォルト：白）

---

## 矢印の操作

- **接続** — 矢印ツールでブロックの辺に近づけると自動スナップ
- **直角ルーティング** — 自動で縦横の折れ線を生成
- **セグメント移動** — 選択中の矢印のセグメントをドラッグして折れ位置を調整
- **端点の移動** — 選択中の矢印の端点（○ハンドル）をドラッグして再接続
- **自動ルートに戻す** — 矢印を選択してセグメントをダブルクリック

---

## カラー

ブロック・矢印を選択すると画面下にカラーパレットが表示されます（24色）。

| 系統 | 内容 |
|------|------|
| パステル12色 | ブルー・ティール・グリーン・イエロー・オレンジ・レッド・ピンク・パープル・シアン・ローズ・グレー・ホワイト |
| 原色12色 | 赤・オレンジ・黄・緑・水色・青・紫・マゼンタ・茶・ダークグレー・チャコール・黒 |

---

## スマートガイド

ブロックを移動・リサイズする際、他ブロックの辺や中心に近づくと自動でスナップし、オレンジのガイドラインが表示されます。

---

## PNG出力について

- 透過PNG（背景なし）で出力
- ブロック・矢印のみを含む最小サイズにクロップ
- PowerPoint などに貼り付けて使用可能

---

## データ形式

JSON形式で保存・読み込みします。ブロック・矢印・グループ・背景色が保存されます。
